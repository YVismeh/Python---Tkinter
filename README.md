# نقشه راه جامع آموزش Tkinter

> [!abstract] معرفی دوره  
> این دوره با هدف آموزش طراحی و پیاده‌سازی رابط گرافیکی در پایتون تهیه شده است. دانشجو پس از یادگیری مبانی پایتون، به‌صورت مرحله‌ای با ویجت‌ها، مدیریت چیدمان، کنترل‌های ورودی، رویدادها، کار با فایل‌ها و طراحی برنامه‌های دسکتاپ آشنا می‌شود.

## اهداف دوره

در پایان این دوره، دانشجو باید بتواند:

- پنجره‌های گرافیکی با استفاده از Tkinter ایجاد کند.
    
- ویجت‌های مختلف را ایجاد و پیکربندی کند.
    
- فرم‌های ورودی و خروجی طراحی کند.
    
- رویدادهای کاربر را مدیریت کند.
    
- ورودی‌ها را اعتبارسنجی کند و خطاهای رایج را مدیریت کند.
    
- اطلاعات را در فایل ذخیره و بازیابی کند.
    
- برنامه‌های گرافیکی را با استفاده از کلاس‌ها سازمان‌دهی کند.
    
- نرم‌افزارهای دسکتاپ کوچک و متوسط طراحی کند.
    
- پروژه‌های کاربردی را از مرحله طراحی تا پیاده‌سازی توسعه دهد.

## پیش‌نیازهای دوره

- آشنایی با متغیرها و انواع داده
    
- دستورات شرطی و حلقه‌ها
    
- توابع و پارامترها
    
- رشته‌ها و ساختارهای داده
    
- مدیریت خطا با `try/except`
    
- مبانی شی‌گرایی در پایتون
    
- آشنایی مقدماتی با کار با فایل‌ها
